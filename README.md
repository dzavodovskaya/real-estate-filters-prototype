# Прототип фильтров недвижимости — материалы для дизайнеров

## Как открыть

1. Распакуйте архив целиком, сохранив структуру папок.
2. Откройте `index.html` в современном браузере. Изображения должны оставаться рядом с HTML-файлом.
3. На компьютере экран отображается в мобильной колонке. Горизонтальную карусель объектов можно перетаскивать мышью, на сенсорном экране — листать пальцем. У правого края также есть стрелка.

Это локальный HTML-прототип, не Figma-файл. Файлы можно отправить коллегам через согласованный в команде канал; адрес 127.0.0.1 с компьютера автора коллегам недоступен. Сохранение поиска зависит от поддержки локального хранилища браузером; для проверки удобнее запускать через локальный веб-сервер.

## Сценарии и логика

- Вверху: «Купить», «Снять», «Посуточно». При переключении с анимацией меняются карточки. Выбор объектов запоминается отдельно по каждому режиму в текущем открытом сеансе.
- Купить: новостройка, вторичка, дом, гараж, офис.
- Снять: квартира, комната, дом, гараж, офис.
- Посуточно: квартира, отель, дом.
- Карточки объектов допускают множественный выбор; выбор обозначен синей рамкой и галочкой. Перетаскивание не должно выбирать карточку.
- Расположение — редактируемый текст, время в пути выбирается из списка. Это демонстрационные поля, без геокодирования или расчёта маршрута.
- Комнаты: студия, 1, 2, 3, 4, 5+. Допускается множественный выбор.
- Ремонт и отделка не показываются, пока не выбран подходящий объект. Для новостройки: без отделки, предчистовая, готовый ремонт. Для вторички и дома: хороший, бабушкин, дизайнерский. Для квартиры и комнаты в аренде используется тот же набор ремонта.
- Можно выбрать несколько вариантов ремонта. Подпись группы ремонта соответствует выбранным объектам. Если выбрана новостройка и вторичка или дом, отображаются оба набора. Если выбран только гараж, блок скрыт; офис и отель сами по себе тоже не показывают блок ремонта в текущем прототипе.
- Если подходящий тип недвижимости снят, скрывшиеся значения ремонта сбрасываются, чтобы не влиять на поиск. «Сбросить» возвращает исходное состояние.
- Счётчик объявлений условный, изменяется по демонстрационной формуле и не связан с реальной базой. Кнопка «Смотреть объявления» показывает сообщение о прототипе, а не реальную выдачу.
- «Сохранить поиск» сохраняет набор в локальном хранилище браузера этого устройства, если оно доступно; это не профиль пользователя и не серверное сохранение. Экран списка сохранённых поисков не реализован.

## Для сборки в Figma

Прототип сделан в HTML/CSS/JavaScript. Прямой перенос исходного файла в Figma не гарантирует сохранения логики, анимации и состояния; интерактивность в Figma потребуется создать отдельно. Этот пакет предназначен как визуальный и функциональный референс. Для детальной реализации обсудите состояния, управление выбранными значениями при смене режима, обработку ошибок и интеграцию с реальным поиском.

## Предлагаемый маршрут демонстрации — 45–60 секунд

1. Показать «Купить» и горизонтальное листание объектов, в том числе свайп и стрелку.
2. Выбрать новостройку: прокрутить к блоку «Ремонт и отделка», показать три варианта.
3. Вернуться наверх, добавить вторичку: показать, что появилась вторая группа и подпись «Во вторичке».
4. Сбросить, выбрать гараж: показать, что блок ремонта отсутствует.
5. Показать «Снять» и «Посуточно»: состав объектов плавно меняется.
6. Коротко показать выбор расположения, времени в пути, комнат и закреплённые нижние кнопки.

Демонстрация должна быть записана с реального прототипа: видео не заменяет интерактивную проверку и не подтверждает наличие серверных интеграций.
